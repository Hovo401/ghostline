# Ghostline — дизайн-бриф

> Статус: v0.2 · 2026-09-28
> Источник правды по внешнему виду — прототип `Ghostline.dc.html` (Claude Design). Этот бриф фиксирует его решения в виде токенов и правил, чтобы перенести их в код.
> Функциональные требования — [REQUIREMENTS.md](REQUIREMENTS.md).

## 0. Коротко

- **Идея:** «из шума — в разговор». Цифровой шум из символов — фирменный образ: он собирается в формы на главной, из него «проявляются» заголовки и новые сообщения. Сам интерфейс при этом спокойный и чистый.
- **Характер:** тихий, современный, без кибер-клише. Почти чёрный фон с зеленоватым оттенком, один яркий акцент (по умолчанию лаймовый «Сигнал»), тонкие линии, моноширинные метки.
- **Громкий вход, тихая работа:** на главной — 3D-сцена из символов, в мессенджере — только микроанимации, которые сообщают о состоянии.
- **Гибкий внешний вид:** 6 тем + своя, 7 акцентов (включая градиенты) + свой, 4 шрифта, размер текста, форма пузырей. Всё — через токены, новые темы добавляются без правки компонентов.

## 1. Принципы

1. **Шум — только как переход.** Символы мелькают, пока текст появляется, и замирают, когда он прочитан. Статичный текст — всегда чистый.
2. **Один акцент.** Акцентом выделено только главное: основная кнопка, свои сообщения, «прочитано», онлайн, счётчики.
3. **Читаемость важнее эффекта.** Контраст текста ≥ 4.5:1 во всех темах; символы на фоне главной бледные, за текстом — подложка.
4. **Движение объясняет состояние:** отправлено, печатает, идёт запись, панель открылась.
5. **Всё через токены.** Ни одного цвета, радиуса или длительности в компонентах напрямую.
6. **Честный текст.** Никаких обещаний шифрования. Позиционирование — «веб-мессенджер без номера телефона, рекламы и ленты».

**«Как в системе»** — не тема, а правило: Тёмная или Светлая по `prefers-color-scheme`.

**Терминал** меняет не только цвета: аватары залиты акцентом, у исходящих пузырей — свечение акцентом (`glow`). Это пример того, что тема управляет и эффектами (§8).

**Своя тема** — пользователь выбирает только фон и текст, остальное выводится смешиванием в OKLab:

| Токен | Формула |
|---|---|
| `bg2` | 94 % фона + 6 % текста |
| `panel` | 90 % фона |
| `in` | 88 % фона |
| `line` | 80 % фона |
| `mute` | 40 % фона + 60 % текста |
| `desk` | 70 % фона + 30 % чёрного |

Тон (светлая или тёмная) определяется по яркости фона. Если контраст `fg`/`bg` ниже 4.5:1 или `mute`/`bg` ниже 3:1 — показать предупреждение под палитрой.

### 2.3 Акценты

Акцент состоит из двух значений: **заливка** (`accent-fill`, может быть градиентом) — кнопки, свои пузыри, бейджи; и **текстовый цвет** (`accent-t`, всегда однотонный) — ссылки, «прочитано», подписи. Текстовый цвет отдельный для светлых тем, чтобы проходить по контрасту.

| Акцент | Заливка | Текст на тёмном | Текст на светлом |
|---|---|---|---|
| Сигнал (по умолчанию) | `#B8F25B` | `#B8F25B` | `#3F7A0C` |
| Ион | `#63E6F2` | `#63E6F2` | `#0A6E7C` |
| Искра | `#FF9152` | `#FF9152` | `#A8420C` |
| Фиалка | `#BBA8FF` | `#BBA8FF` | `#5A3ED0` |
| Аврора | `linear-gradient(135deg, #22D3EE, #D946EF)` | `#5EE6F0` | `#0A6E7C` |
| Закат | `linear-gradient(135deg, #FFB14A, #FF4D8D)` | `#FF8A5C` | `#B03A1A` |
| Мята | `linear-gradient(135deg, #C6F25B, #3CE0C0)` | `#9AF07A` | `#2F7A3A` |
| Свой | цвет или градиент из двух цветов | первый цвет | первый цвет, затемнённый до контраста 4.5:1 |

`ink` (текст на заливке) — `#0B0D0C` для светлых акцентов; для своего акцента выбирается автоматически по яркости: тёмный или белый.

## 5. Фирменные элементы

| Элемент | Как работает | Где |
|---|---|---|
| **Расшифровка** | Текст сначала состоит из случайных символов (`A–F 0–9 # % & * + = < > / { } [ ] $ @ Ж Щ Ю Я Б Д Ф Л Σ Ω Δ λ § ± ≈`), которые слева направо фиксируются в настоящие. Длительность `min(1300, 380 + 16 × длина)` ms, кадр раз в 45 ms. У последних сообщений — каскад с шагом 70 ms | Заголовки главной и входа, новые сообщения, предпросмотр в настройках |
| **Поле символов** | 3D-облако глифов (§6) | Главная, правая половина экрана входа |
| **Точки «печатает»** | Три точки 6 px, по очереди поднимаются на 3 px, 900 ms, сдвиг 150 ms | Список чатов, лента |
| **Курсор-блок** | Прямоугольник 9×19 px с заливкой акцента после слова `ghostline` | Логотип |
| **Моно-статусы** | `13:43 · ✓✓ прочитано` моношрифтом под пузырём | Лента |

**Логотип:** вордмарк `ghostline` (Geologica 600, 20 px, трекинг −0.02em) + курсор-блок. В рейке — квадрат 36 px с буквой `g` на заливке акцента.

### 6.2 3D-сцена «Поле символов»

- Одна геометрия `THREE.Points`, один draw call. Каждая частица — глиф из атласа 8×8 (64 символа: цифры, hex, знаки, кириллица, греческие буквы, блоки `░▒▓`, буквы слова «ghostline»), нарисованного JetBrains Mono на canvas.
- **Сюжет по скроллу** (прогресс 0 → 3 в вершинном шейдере, у каждой частицы своя задержка):

| Этап | Форма |
|---|---|
| 0 | Облако (A), сфера (B) или стена (C) |
| 1 · Вход | Сфера (распределение Фибоначчи, радиус 1.9) |
| 2 · Связь | Два шара, соединённые волнистой линией — два собеседника |
| 3 · Тишина | Слово `ghostline`; символы перестают меняться и замирают |

- **В покое** частицы плавают, символы у каждой частицы меняются со своей скоростью.
- **Курсор** расталкивает частицы в радиусе ~1.1; попавшие под курсор увеличиваются, окрашиваются в акцент и перестают мерцать. Группа слегка поворачивается за мышью.
- **Цвета** берутся из CSS-переменных темы: `fg`, `accent-t`, `glyph-a` (обновление раз в 30 кадров). ~4.5 % частиц всегда акцентные.
- **Количество частиц:** 2600 на десктопе, 1300 на телефоне; множитель качества .6 / 1 / 1.5. На экране входа — 1600, этап 1 (сфера).
- **Производительность:** DPR ≤ 2; рендер на паузе вне экрана; без WebGL — сцена не рисуется, страница работает. Three.js — отдельный ленивый чанк, в `/app` не загружается. При `prefers-reduced-motion` — статичная сфера без мерцания.
- Прототип написан на чистом Three.js с собственными шейдерами — его можно перенести почти как есть в компонент React (обёртка над custom element или React Three Fiber).

## 7. Экраны

### 7.1 Вход и регистрация

- Две колонки: слева форма (до 420 px), справа — `bg2` с полем символов и подписью `ВЕБ-МЕССЕНДЖЕР · БЕЗ УСТАНОВКИ` / «Откройте вкладку — и пишите.» с расшифровкой. На телефоне — только форма.
- Сегмент «Вход / Регистрация».
- **Вход:** «С возвращением», поля «Имя пользователя» и «Пароль», кнопка неактивна (прозрачность .45), пока поля пустые; `Enter` отправляет; ссылки «Войти по фразе восстановления» и «Создать аккаунт».
- **Регистрация, шаг 1** (`ШАГ 1 ИЗ 2`): username — ввод приводится к `a–z 0–9 _`, подсказка моношрифтом: «Латиница, цифры и _» → «Минимум 3 символа» → «@имя свободно» (акцент) / «@имя уже занято» (красный). Пароль — шкала из 4 делений: красный → жёлтый → акцент; подпись «Слишком короткий / Средний / Надёжный / Очень надёжный».
- **Регистрация, шаг 2** (`ШАГ 2 ИЗ 2`): 12 пронумерованных слов в сетке 3×4 моношрифтом, размыты (blur 7 px) до кнопки «Показать фразу»; чекбокс «Я записал фразу в надёжном месте»; «Назад» и «Создать аккаунт» (активна после показа и отметки).
- **Вход по фразе** (в прототипе нет — дорисовать): username, 12 полей для слов с автопереходом и вставкой всей фразы, затем новый пароль.

### 7.2 Мессенджер

**Рейка (десктоп):** логотип `g`, «Чаты» (глиф `○`, при непрочитанных — `◉`), «Настройки» (`◐`), внизу — мой аватар (ведёт в профиль).

**Список чатов:** заголовок «Чаты» и кнопка «Новый», поле «Поиск». Строка: аватар 44 px с точкой онлайн · имя · время · превью (`Вы: …`, `Олег: …`, `Голосовое · 0:12`, `Файл · Договор_v3.pdf`) или акцентное «печатает» с точками · бейдж непрочитанных (заливка акцента). Активный чат — фон `bg2`.

**Шапка чата (68 px):** аватар и имя (клик открывает профиль), статус моношрифтом (`в сети` / `был час назад` / `печатает…` акцентом), справа — кнопка таймера («Таймер: выкл» / «Исчезают: 1 д», при включённом — акцентом; клик переключает по кругу).

**Лента** на фоне `bg2`:
- Входящие: `in` + рамка `line`; свои: заливка акцента, текст `ink`, в теме Терминал — со свечением.
- Имя отправителя в группе — акцентом, только у первого в серии; между сменой автора — отступ 12 px.
- Под пузырём: `13:42 · ✓✓ прочитано` (последнее своё — словом, остальные — значком: `◷` отправка, `✓` отправлено, `✓✓` доставлено/прочитано); «прочитано» — акцентом.
- **Фото:** карточка 300 px, 4:3, подпись под ним.
- **Файл:** 280 px, «лист» 42×50 с расширением (`PDF`, `XLS`), имя, размер моношрифтом.
- **Голосовое:** 270 px, круглая кнопка ▶/❚❚ (у своих — `ink` на акценте наоборот), волна из 28 столбиков — проигранная часть яркая, остальные .35–.55, длительность.
- **Кружок:** круг 210 px, кольцо прогресса акцентом по краю (conic-gradient), кнопка ▶ по центру, длительность внизу.
- «Печатает» — пузырь с точками.

**Поле ввода:** скрепка (меню «Фото или видео» / «Файл» над полем), «пилюля» «Сообщение»; без текста — кнопки микрофона и камеры, с текстом — круглая «↑» на заливке акцента.

**Запись голосового:** поле превращается в «Отмена» · пилюля с мигающей красной точкой, таймером и живой волной акцентом · «↑».

**Запись кружка:** оверлей на чат (фон `bg` 88 % + blur 8 px), круг 260 px с красным кольцом прогресса, `● 0:12 / 1:00`, «Отмена» / «Отправить»; через 60 с — отправка автоматически.

**Панель профиля (380 px, на телефоне — весь экран):** выезжает справа за 500 ms `cubic-bezier(.2,.8,.2,1)`, под ней затемнение; содержимое появляется каскадом (сдвиг 14 px, задержки 80–320 ms). Сверху вниз: аватар 112 px в кольце акцента с точкой онлайн, имя, @username акцентом, статус · кнопки «Без звука» и «Поиск» · «О СЕБЕ» · «Медиа» (сетка 3 колонки, фото квадратные, кружки круглые) и счётчики · список «Исчезающие сообщения / Уведомления / Заблокировать (или Покинуть группу)» красным.

### 7.3 Настройки

Слева — список разделов (Профиль, Внешний вид, Конфиденциальность, Уведомления, Устройства, О приложении), на телефоне — стрелка назад и сегмент разделов.

**Профиль:** аватар 104 px в кольце акцента, «Загрузить фото» / «Удалить»; «Имя» и «Имя пользователя» (моно, подсказка `ghostline.app/@имя`); «О себе» со счётчиком `42 / 140`; блок «Кто что видит» с двумя переключателями; карточка `ТАК ВАС ВИДЯТ ДРУГИЕ`; «Сохранить» и «✓ Сохранено» (исчезает через 2 с).

**Внешний вид:** см. §8.

**Переключатели:** 44–48 × 26–28 px, включён — заливка акцента с кружком цвета `ink`; выключен — `line` с кружком `fg`.

## 8. Система внешнего вида

### 8.1 Оси

| Ось | Значения | По умолчанию |
|---|---|---|
| Тема | `dark`, `light`, `system`, `midnight`, `paper`, `terminal`, `custom` | `dark` |
| Акцент | `signal`, `ion`, `ember`, `violet`, `aurora`, `sunset`, `mint`, `custom` | `signal` |
| Шрифт | `sans` (Geologica), `mono`, `pixel`, `serif` | `sans` |
| Размер текста | `s`, `m`, `l` | `m` |
| Форма пузырей | `round`, `sharp` | `round` |
| Анимация появления | вкл / выкл; при `prefers-reduced-motion` — выкл | вкл |

Оси независимы: любая тема × любой акцент × любой шрифт.

### 8.2 Как это устроено

- Атрибуты на корне: `data-theme`, `data-tone` (light/dark — для выбора текстового цвета акцента), `data-accent`, `data-font`, `data-scale`, `data-bubble`. Каждая комбинация — набор CSS-переменных; компоненты используют только переменные (`var(--bg)`, `var(--accent-fill)` …).
- Тема `custom` и акцент `custom` генерируют CSS-блок в рантайме из выбранных цветов (§2.2).
- До загрузки React инлайн-скрипт в `index.html` читает настройки из localStorage и ставит атрибуты — нет вспышки не той темы. Затем настройки синхронизируются с сервером (`PATCH /api/v1/me/settings`), при конфликте побеждает более свежее `updatedAt`.
- Смена темы — плавный переход фона 300 ms.
- Литералы цветов в компонентах запрещены линтером. Tailwind v4 связывает утилиты с переменными через `@theme`.

### 8.3 Контракт темы

```ts
interface ThemeManifest {
  id: string;                 // 'midnight'
  name: string;               // 'Полночь'
  tone: 'light' | 'dark';     // от тона зависит текстовый цвет акцента
  colors: {
    bg: string; bg2: string; panel: string; line: string;
    fg: string; mute: string; in: string; desk: string;
  };
  glyphAlpha: number;         // прозрачность символов 3D-сцены
  effects?: {
    avatarFilled?: boolean;   // аватары залиты акцентом (Терминал)
    outgoingGlow?: boolean;   // свечение своих пузырей (Терминал)
  };
  preview: { bg: string; inBubble: string }; // для карточки в настройках
}

interface AccentManifest {
  id: string;                 // 'aurora'
  name: string;               // 'Аврора'
  fill: string;               // цвет или градиент
  text: { dark: string; light: string };
}
```

**Новая тема или акцент** — один файл в `frontend/src/themes/` и запись в реестре, без правки компонентов. `pnpm test:themes` проверяет полноту токенов и контраст (`fg`/`bg`, `mute`/`bg`, `ink`/заливка, `accent-t`/`bg` ≥ 4.5:1) и делает скриншоты витрины `/dev/themes`.

### 8.4 Экран «Внешний вид»

- `ПРЕДПРОСМОТР`: входящее и своё сообщение (своё — с расшифровкой), статус `19:02 · ✓✓ прочитано`.
- «Тема»: карточки с мини-превью (фон + два пузыря), кольцо выбора; при «Своя» — пунктирная панель с двумя пипетками «Фон» и «Текст» и hex-кодами.
- «Акцент»: круги 44 px с подписями, выбранный — кольцо `fg`; у «Свой» — значок «+». Под ними — панель «Цвет 1», «Цвет 2», переключатель «Градиент» (сплошная рамка, когда выбран свой акцент).
- «Шрифт»: карточки «Аа» каждым шрифтом.
- «Размер текста» и «Форма сообщений» — сегменты.
- «Анимация появления» — переключатель с пояснением «Новые сообщения проявляются из шума».

## 9. Анимации

| Событие | Анимация | Время |
|---|---|---|
| Новое сообщение | Расшифровка текста | 380–1300 ms |
| Открытие чата | Расшифровка последних сообщений каскадом | шаг 70 ms |
| Печатает | Прыгающие точки | цикл 900 ms |
| Статус своего сообщения | `◷` → `✓` → `✓✓` → «прочитано» акцентом | по событиям |
| Панель профиля | Выезд + затемнение + каскад содержимого | 500 ms |
| Смена темы | Переход цвета фона | 300 ms |
| Шкала пароля, переключатели | Переход цвета / положения | 200–250 ms |
| Запись | Красная точка мигает; волна обновляется | 120 ms |
| Размытие фразы | Снятие blur | 300 ms |
| Главная | Морфинг сцены по скроллу, отталкивание курсором | непрерывно |

Правила: анимируются только `transform`, `opacity`, `filter`, цвета. При `prefers-reduced-motion` расшифровка, мерцание символов и каскады отключаются. Ничего не мигает чаще 3 раз в секунду.

## 10. Доступность

- Контраст WCAG 2.2 AA во всех встроенных темах; для своей темы — предупреждение.
- Видимый фокус с клавиатуры (обводка `accent-t`) — в прототипе его нет, добавить.
- Кнопки-иконки с `aria-label` (в прототипе — `title`); переключатели — `role="switch"`.
- Расшифровка не мешает скринридерам: настоящий текст — в `aria-label`, анимированный — `aria-hidden`.
- Цели касания на телефоне ≥ 44 px.
